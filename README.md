# 📊 Analyze the Data – Data Analytics Web Application

## 📌 Project Overview

Analyze the Data is a web-based Data Analytics application developed using Python, Flask, Pandas, HTML, CSS, and JavaScript.

The application allows users to upload CSV datasets, explore data, calculate statistical measures, identify missing values, and visualize meaningful insights through interactive charts.

## 🎯 Project Objectives

- Analyze uploaded CSV datasets.
- Display total rows and columns.
- Calculate Mean, Median, Minimum, and Maximum.
- Identify missing values in datasets.
- Display column information and data types.
- Generate data visualizations.
- Provide a responsive and user-friendly interface.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to Project Folder

```bash
cd Data_Analysis_Project
```

### Step 3: Install Required Libraries

```bash
pip install flask pandas numpy
```

### Step 4: Run the Application

```bash
python main.py
```

### Step 5: Open in Browser

```text
http://127.0.0.1:5000
```
